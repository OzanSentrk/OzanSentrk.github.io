Advanced File Search

In this Python-based desktop application I developed, users can select a folder or drive containing PDF, Excel, Word, or PowerPoint files to scan. Through a built-in search functionality, users can type in any term or concept they remember related to the document they are looking for. The search operates based on both semantic and keyword matching, providing a list of relevant documents from the scanned directory. This application significantly simplifies the process of finding old documents for individuals working with large datasets, saving them valuable time and effort.
